02 — de qué va esto en 20 segundos

Remotion es video hecho con código. La skill se lo enseña a Claude.

  • Remotion — un framework para crear video con React. Cada frame es código, así que se puede animar, sincronizar y renderizar con precisión de milisegundo.
  • La skill de Remotion — 28 reglas que le enseñan a Claude a escribir Remotion bien (timing, audio, composición). Sin ella escribe animaciones genéricas; con ella trata el video como lo que es.
  • Tú — describes el video en tu idioma. Claude escribe el código, tú lo revisas en el studio y lo mueves a ojo. No tocas una línea si no quieres.

# no necesitas saber React. Sí ayuda saber pedir bien — para eso es la sección 05.

03 — instalación (una vez y ya)

De cero a studio abierto

Necesitas Node 18+ instalado. Lo demás es copiar y pegar. Cinco comandos.

Terminal — zsh
# 1. instala Claude Code $ npm install -g @anthropic-ai/claude-code # 2. arranca un proyecto de video (elige plantilla en blanco) $ npm create video@latest $ cd mi-video # 3. instala la skill de Remotion en el proyecto $ npx skills add remotion-dev/skills ✓ remotion-best-practices → .claude/skills/ # 4. abre Claude Code dentro del proyecto $ claude
  • npx skills add remotion-dev/skills deja las reglas en .claude/skills/. Claude las carga solo al arrancar dentro de la carpeta — no tienes que activarlas.
  • Para tenerlas en todos tus proyectos, corre el mismo comando apuntando a ~/.claude/skills/ (global).

05 — los prompts (esto es el oro)

Los 3 prompts con los que lo monté

Cópialos, cambia lo que está en [corchetes rojos] por lo tuyo, y pégalos en Claude Code. En ese orden.

A

B-rolls que caen justo donde hablas

~ prompt-brolls.md
# tengo un video mío hablando, quiero b-rolls encima Tengo un video en public/toma.mp4 donde hablo de [tema]. Móntame una composición de Remotion así: 1) mi voz corre por debajo TODO el tiempo, sin cortes. 2) cuando digo "[palabra]" (sobre el seg [12]), mete un b-roll a pantalla completa [3] seg y luego vuelve a mí. 3) genera o usa los b-rolls de public/brolls/ y colócalos en el timeline donde toca, no al azar. Déjalo abierto en el studio para que yo lo mueva a ojo.

Por qué funciona: le das el ancla exacta (la palabra + el segundo), así el b-roll cae donde tiene sentido, no relleno. Y el cierre — "para que yo lo mueva a ojo" — le dice que no cierre nada, que te deje el control fino a ti.

B

Que el audio no se corte ni con los b-rolls encima

~ prompt-audio.md
# el problema clásico: el b-roll se lleva el audio con él Mi voz está dentro de public/toma.mp4. Sácala a una pista de audio propia que suene de principio a fin. Los b-rolls que entren encima van MUDOS: solo imagen. Así se ve el b-roll pero se me sigue oyendo a mí. Si uso public/musica.mp3, bájala a [-18 dB] cuando hablo y súbela en los silencios. Enséñame la estructura de Sequences antes de renderizar.

Por qué funciona: el error típico es meter el b-roll como video-con-sonido y que pise tu voz. Aquí separas una pista de audio continua + capas de solo-imagen encima. Pedirle que te enseñe la estructura antes de renderizar te deja revisar sin gastar un render.

así queda por dentro — src/Video.tsx
<AbsoluteFill> // 1 pista de voz, corre los 0 → 900 frames enteros <Audio src={staticFile("voz.mp3")} /> // b-roll MUDO, solo del frame 120 al 210 <Sequence from={120} durationInFrames={90}> <OffthreadVideo muted src={staticFile("brolls/mapa.mp4")} /> </Sequence> </AbsoluteFill>

# no tienes que escribir esto. Es solo para que veas que "audio por debajo + b-roll mudo encima" es literalmente cómo lo arma.

C

El demo del bot de WhatsApp, de cero

~ prompt-demo-bot.md
# no tengo el producto grabado, necesito el demo para vender Móntame en Remotion un mockup de chat de WhatsApp, vertical [1080x1920]. Es un bot de [inmobiliaria] que califica un lead: pregunta [zona, presupuesto, crédito y fecha] y al final dice "te paso con tu asesora". - las burbujas van apareciendo con timing real de tecleo - "en línea", doble check azul, y la hora en cada mensaje - fondo y verdes idénticos a WhatsApp Que parezca una captura de verdad, no un dibujo.

Por qué funciona: le das el guion del chat (las 4 preguntas + el cierre), no "hazme un chat". El detalle que lo vuelve creíble es el último renglón: "que parezca una captura de verdad, no un dibujo" — eso empuja a Claude a clavar los verdes, las tildes y el timing.

06 — exporta el video

Un comando y tienes tu .mp4

Cuando en el studio ya se ve bien, sales del navegador y renderizas desde la terminal.

Terminal — render
# CompositionId es el nombre que ves arriba a la izq del studio $ npx remotion render MiVideo out/video.mp4 ✓ Rendered · out/video.mp4
  • Vertical para reel/TikTok: pídele en el prompt 1080x1920 y listo, no cambia el comando.
  • ¿Un cambio de última hora? No re-grabas: le dices a Claude qué mover, se actualiza el studio, y vuelves a renderizar.
